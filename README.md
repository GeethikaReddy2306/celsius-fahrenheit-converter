# 🌡️ Celsius ↔ Fahrenheit Converter

A simple and responsive **Temperature Converter** built using **HTML, CSS, and JavaScript**. This web application allows users to instantly convert temperatures between **Celsius (°C)** and **Fahrenheit (°F)** through an intuitive and user-friendly interface.

---

## 🌐 Live Demo

🔗 Live Website: https://celsius-fahrenheit-converter.vercel.app/



---

## ✨ Features

- 🌡️ Convert Celsius (°C) to Fahrenheit (°F)
- 🌡️ Convert Fahrenheit (°F) to Celsius (°C)
- ⚡ Instant conversion
- ✅ Input validation
- 📱 Fully responsive design
- 🎨 Clean and modern user interface
- 💻 Beginner-friendly project

## 🧮 Temperature Conversion Formulas

### Celsius → Fahrenheit

```text
°F = (°C × 9/5) + 32
```

### Fahrenheit → Celsius

```text
°C = (°F − 32) × 5/9
```
